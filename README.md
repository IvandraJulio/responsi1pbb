# 📚 Library Book Loan Management REST API

Layanan RESTful API sederhana dan handal untuk pencatatan dan pengelolaan peminjaman buku perpustakaan, dibangun menggunakan **Node.js**, **Express.js**, dan database cloud **Supabase (PostgreSQL)**, serta siap di-deploy secara serverless ke **Vercel**.

## 🎯 Deskripsi Umum & Tujuan Proyek

Proyek ini bertujuan untuk menyediakan backend API modular yang mempermudah proses pencatatan sirkulasi peminjaman dan pengembalian buku di perpustakaan. Sistem ini memfasilitasi operasi:
1. **Pencatatan Peminjaman Baru (Create)**: Merekam data anggota, buku yang dipinjam, tanggal pinjam, dan batas waktu kembali.
2. **Melihat & Memfilter Data Peminjaman (Read & Query Filter)**: Menampilkan seluruh data peminjaman dengan fitur pencarian dan penyaringan fleksibel (misal berdasarkan status `Terlambat`, `Dipinjam`, `Kembali`, atau nama anggota/judul buku).
3. **Pembaruan Data & Pengembalian Buku (Update)**: Memperbarui status peminjaman dan mencatat tanggal pengembalian.
4. **Penghapusan Catatan Peminjaman (Delete)**: Menghapus data sirkulasi yang tidak diperlukan/salah input.
5. **Statistik Peminjaman (Summary Statistics)**: Menampilkan agregasi data peminjaman aktif, selesai, dan terlambat.

## 🗄️ Struktur Data & Skema Database

Tabel utama yang digunakan bernama **`loans`** di Supabase.

### Kamus Data (Data Dictionary)

| Kolom | Tipe Data | Nullable | Default | Deskripsi |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `BIGINT` | No | Auto Increment | ID unik peminjaman (Primary Key) |
| `member_name` | `VARCHAR(150)` | No | - | Nama lengkap anggota perpustakaan |
| `member_id` | `VARCHAR(50)` | No | - | Nomor Induk / ID Anggota (cth: `MBR-001`) |
| `book_title` | `VARCHAR(255)` | No | - | Judul buku yang dipinjam |
| `book_code` | `VARCHAR(50)` | No | - | Kode inventaris buku / ISBN (cth: `BK-001`) |
| `loan_date` | `DATE` | No | `CURRENT_DATE` | Tanggal awal peminjaman buku |
| `due_date` | `DATE` | No | - | Tanggal batas akhir pengembalian (tenggat waktu) |
| `return_date` | `DATE` | Yes | `NULL` | Tanggal buku dikembalikan secara riil |
| `status` | `VARCHAR(50)` | No | `'Dipinjam'` | Status peminjaman (`Dipinjam`, `Kembali`, `Terlambat`, `Hilang`) |
| `notes` | `TEXT` | Yes | `NULL` | Catatan tambahan kondisi buku atau keterangan denda |
| `created_at` | `TIMESTAMPTZ` | No | `NOW()` | Waktu data dibuat |
| `updated_at` | `TIMESTAMPTZ` | No | `NOW()` | Waktu data terakhir diperbarui |

### Script SQL Supabase (`schema.sql`)

Jalankan query berikut di **SQL Editor** pada Dashboard Supabase Anda:

```sql
-- 1. Buat Tabel loans
CREATE TABLE IF NOT EXISTS public.loans (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    member_name VARCHAR(150) NOT NULL,
    member_id VARCHAR(50) NOT NULL,
    book_title VARCHAR(255) NOT NULL,
    book_code VARCHAR(50) NOT NULL,
    loan_date DATE NOT NULL DEFAULT CURRENT_DATE,
    due_date DATE NOT NULL,
    return_date DATE DEFAULT NULL,
    status VARCHAR(50) NOT NULL DEFAULT 'Dipinjam',
    notes TEXT DEFAULT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 2. Buat Index untuk Optimasi Filtering
CREATE INDEX IF NOT EXISTS idx_loans_status ON public.loans(status);
CREATE INDEX IF NOT EXISTS idx_loans_member_id ON public.loans(member_id);
CREATE INDEX IF NOT EXISTS idx_loans_member_name ON public.loans(member_name);

-- 3. Data Awal / Dummy Data (Opsional untuk Uji Coba)
```

## 📡 Dokumentasi Endpoint API

Base URL (Lokal): `http://localhost:3000`  
Base URL (Vercel): `https://<your-project-name>.vercel.app`

| No | Method | Endpoint | Deskripsi | Query Params (Opsional) |
| :--- | :--- | :--- | :--- | :--- |
| 1 | `GET` | `/` | Root / Cek Status API & Panduan Endpoint | - |
| 2 | `GET` | `/api/loans` | Mendapatkan semua data peminjaman buku | `status`, `member_name`, `book_title`, `member_id`, `sort_by`, `order`, `page`, `limit` |
| 3 | `GET` | `/api/loans/:id` | Mendapatkan detail 1 peminjaman berdasarkan ID | - |
| 4 | `POST` | `/api/loans` | Menambahkan catatan peminjaman buku baru | - |
| 5 | `PUT` | `/api/loans/:id` | Memperbarui data peminjaman / proses pengembalian | - |
| 6 | `DELETE` | `/api/loans/:id` | Menghapus data peminjaman | - |
| 7 | `GET` | `/api/loans/stats/summary` | Melihat ringkasan total data per status | - |

## 🚀 Panduan Instalasi & Menjalankan Lokal

### 1. Clone Repository
```bash
git clone https://github.com/IvandraJulio/responsi1pbb.git
cd responsi1pbb
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Konfigurasi Environment Variables
Salin file `.env.example` menjadi `.env`:
```bash
cp .env.example .env
```
Buka file `.env` dan isi dengan kredensial Supabase Anda:
```env
PORT=3000
SUPABASE_URL=https://xxxxxxxxxxxxxxxxxxxx.supabase.co
SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```
*(URL dan Key dapat diperoleh dari Supabase: **Project Settings** -> **API**)*

### 4. Eksekusi Skema Database
Buka dashboard Supabase, masuk ke menu **SQL Editor**, salin dan jalankan isi file `schema.sql`.

### 5. Jalankan Server
- **Mode Development (Auto-reload)**:
  ```bash
  npm run dev
  ```
- **Mode Production**:
  ```bash
  npm start
  ```
Akses API pada browser atau Postman di: `http://localhost:3000`

## ☁️ Panduan Deployment ke Vercel

1. **Push kode ke GitHub**:
   Pastikan seluruh kode telah di-push ke repository GitHub Anda (`https://github.com/IvandraJulio/responsi1pbb`).

2. **Hubungkan ke Vercel**:
   - Buka [Vercel Dashboard](https://vercel.com/dashboard).
   - Klik **"Add New..."** -> **"Project"**.
   - Pilih dan Import repository **`responsi1pbb`**.

3. **Atur Environment Variables di Vercel**:
   Di bagian **Environment Variables**, tambahkan 2 variabel wajib berikut:
   - `SUPABASE_URL` = `https://xxxxxxxxxxxxxxxx.supabase.co`
   - `SUPABASE_ANON_KEY` = `<anon_public_key_supabase_anda>`

4. **Klik Deploy**:
   Vercel akan secara otomatis membangun aplikasi serverless Anda. Setelah selesai, Anda akan mendapatkan URL publik (contoh: `https://responsi1pbb.vercel.app`).
